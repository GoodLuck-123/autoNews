### 1. 捷克语 LLM 语用推理基准测试
- 核心技术突破：构建捷克语语用推理评测基准，考查大语言模型的跨语言语用理解能力。
- 开源情况：未提供开源链接。
- 工业落地可行性：低——面向单一语言的小众评测场景，难以直接形成通用工业价值。

### 2. 多智能体 LLM 中控制流与数据流分离的稳定提示优化
- 核心技术突破：提出将提示词中“生成内容”与“执行协议”解耦，避免优化内容生成时破坏消息路由、输出格式等关键控制逻辑。
- 开源情况：未提供开源链接。
- 工业落地可行性：高——直接解决多 Agent 系统提示优化的稳定性痛点，工程适配价值明确。

### 3. 原生统一多模态模型的理解-生成协同机制研究
- 核心技术突破：在无预训练视觉先验的可控环境下，从表示、任务、系统三个层面揭示理解与生成目标间协同或竞争的关系。
- 开源情况：未提供开源链接。
- 工业落地可行性：中——为多模态统一模型架构设计提供指导，但属机制性研究，落地周期较长。

### 4. EM²Mem：面向大模型的事件中心多模态记忆
- 核心技术突破：提出以事件为中心的多模态记忆框架，将异构证据绑定为生成就绪的格式，改善长视频问答中的跨模态与时间对齐。
- 开源情况：已提供 GitHub 链接：https://github.com/zjunlp/LightMem
- 工业落地可行性：高——直连长视频问答场景，且已有开源实现支撑快速验证。

### 5. ReFlowSET：表示对齐的 SAR 到光学影像翻译
- 核心技术突破：提出表示对齐的潜流匹配方法，显式处理隐空间编码器选择对 SAR 条件与光学目标往返重建保真度的影响。
- 开源情况：已提供 GitHub 链接：https://github.com/KAIST-VICLab/ReFlowSET
- 工业落地可行性：中——遥感影像翻译需求明确，但受限于特定领域数据与业务验证。
